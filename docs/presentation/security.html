Security by design

The system protects the case at every handoff.

AUTHENTICATION

Password hashing, sessions, regeneration, CSRF tokens, and expiring reset tokens protect accounts.

AUTHORIZATION

Role guards and scoped queries ensure that users see only the work they are permitted to manage.

FILE EVIDENCE

MIME detection, random names, private storage, and authorized download checks harden attachments.

ACCOUNTABILITY

Audit logs record sensitive actions; anonymous complaints hide identity from operational staff.

Security principle: every sensitive action should be verified, scoped, and explainable after the fact.
