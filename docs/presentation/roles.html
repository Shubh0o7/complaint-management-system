Four workspaces.
One shared process.
Role-based design

The interface changes with responsibility.

Each role sees the work it is accountable for—without losing the shared complaint timeline.

Complainant

Submit, search, comment, receive updates, and rate resolutions.

Administrator

Route cases, manage users, export reports, and review audit activity.

Department manager

Review scoped workload, assign officers, and monitor SLA health.

Complaint officer

Investigate assigned cases and record progress toward resolution.
